# CAOZ | Portal Oficial 🎮✨

Sitio web oficial del creador de contenido y streamer **Caoz** (+2.17M de comunidad consolidada).

---

## 🚀 Estructura del Sitio

* **Inicio (`#hero`)**: Presentación oficial, bio interactiva y enlaces directos.
* **Métricas (`#metrics`)**: Cifras y estadísticas consolidadas en YouTube, TikTok, Twitch, Kick e Instagram (+2.17M de seguidores).
* **Marcas & Patrocinios (`#brands`)**: Alianzas y patrocinios comerciales oficiales (Red Bull, Logitech G, Kick Streaming).
* **Contacto Comercial (`#contact`)**: Correo oficial y formulario para propuestas comerciales, colaboraciones entre creadores, prensa y activaciones de eventos.

---

## 🛠️ Tecnologías

* **Framework**: Next.js 16 (App Router)
* **Frontend**: React 19, Tailwind CSS v4, Lucide Icons
* **Estilos**: Tailwind CSS con estética cyberpunk/gaming moderna

---

## 💻 Ejecución Local

1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
3. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
